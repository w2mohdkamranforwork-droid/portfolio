PROJ-02 Completed

Python MCQ Generator

An interactive AI tool that ingests raw documents and transforms them into structured multiple-choice evaluation datasets, validated against strict JSON schemas.

PythonOpenAIJSON ParsingAPI Integration

Working Purpose

Writing good multiple-choice questions by hand is slow. This tool automates that process: feed it raw study material, and it uses the OpenAI API to generate a structured set of questions, options, and correct answers — ready to drop straight into a quiz or assessment.

Every response is validated against a strict JSON schema before it's accepted, so malformed or incomplete question objects never make it into the final dataset.

Tech Stack

Python

Core scripting language orchestrating document parsing and API calls.

OpenAI API

Generates contextually relevant multiple-choice questions from source text.

JSON Schema Validation

Guarantees every generated question object is well-formed before use.

Key Features

  • → Ingests raw text or documents and generates contextually relevant MCQs.
  • → Strict JSON schema validation to guarantee well-formed question objects.
  • → Designed for educators and students to auto-generate practice tests quickly.
  • → Structured output ready to plug into any downstream quiz or LMS tool.
