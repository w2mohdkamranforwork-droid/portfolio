SYS-02 Under Active Construction

Street Cart Vendor Finder

A dynamic real-time vendor tracking and mapping network that helps customers discover nearby street food vendors, leveraging spatial browser hardware alongside a structured relational backend.

C#Web APISQL ServerEF CoreBootstrap

Working Purpose

Street vendors are constantly moving, which makes them hard for regular customers to find consistently. This project addresses that gap with a location-aware platform: vendors share their live position, and customers can browse a map to find carts nearby in real time.

The backend exposes a REST API for location updates and vendor lookups, while the relational data layer keeps vendor profiles, categories, and location history organized for fast querying.

Tech Stack

C# / ASP.NET Core Web API

RESTful backend serving vendor location and profile data.

SQL Server / EF Core

Relational storage accessed through EF Core and LINQ for type-safe queries.

HTML5 Geolocation API

Captures live device coordinates directly in the browser.

Bootstrap

Responsive UI so the map and vendor list work well on mobile devices.

Key Features

  • → Live vendor location tracking using the browser's built-in Geolocation API.
  • → RESTful Web API backend built on ASP.NET Core for location and profile data.
  • → EF Core with LINQ for efficient, type-safe database access.
  • → Responsive Bootstrap interface designed for on-the-go mobile use.
