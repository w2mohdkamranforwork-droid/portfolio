Suicidal Behaviour Prediction

A full-stack Diploma capstone application engineered to parse structured user responses and session metadata to help categorize risk factors as an early-warning support tool.

HTML5JavaScriptBootstrapMongoDB
This was an academic capstone project exploring risk-indicator screening, not a clinical or diagnostic tool. If you or someone you know is struggling, please reach out to a licensed mental health professional or a crisis helpline in your region.

Working Purpose

Built as a final-year diploma project, this application explores how a structured questionnaire combined with session behavior data could help flag risk indicators early, giving support staff or counselors a starting signal rather than a final judgment.

The system captures responses through a guided web form, stores them in a flexible document schema, and surfaces a risk categorization based on the collected data.

Tech Stack

HTML5 / JavaScript

Structures and drives the guided questionnaire interface.

Bootstrap

Responsive layout so the form works cleanly on any device.

MongoDB

Document storage for flexible, evolving response schemas.

Key Features

  • → Structured questionnaire capturing behavioral and situational indicators.
  • → Session metadata analysis to help surface a risk categorization.
  • → MongoDB storage for flexible, schema-light response records.
  • → Responsive Bootstrap interface accessible from any device.
