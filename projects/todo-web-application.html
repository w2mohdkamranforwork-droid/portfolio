PROJ-01 Completed

To-Do Web Application

A full-stack task management application built with Flask and SQLite, with a seamless CRUD lifecycle and dynamic Jinja templates that reflect state changes in real time.

PythonFlaskSQLiteJinja2JavaScript

Working Purpose

Built as a focused exercise in full-stack Python development, this app lets a user create, organize, and complete tasks without any of the friction of heavier project-management tools. It was designed to be simple enough to self-host and fast enough to use as a daily driver.

The server renders task lists via Jinja2 templates on each request, keeping the client lightweight while JavaScript handles small interactive touches like marking a task complete without a full page reload.

Tech Stack

Python / Flask

Lightweight WSGI framework handling routing and request logic.

SQLite

Zero-config, file-based database for persistent task storage.

Jinja2

Server-side templating for fast, dynamic HTML rendering.

JavaScript

Small client-side enhancements for instant UI feedback.

Key Features

  • → Full CRUD task lifecycle — add, edit, complete, and delete — with instant UI feedback.
  • → Server-rendered Jinja2 templates for fast initial page loads.
  • → SQLite for simple, zero-config persistent storage.
  • → Clean, minimal interface focused on daily task workflows.
